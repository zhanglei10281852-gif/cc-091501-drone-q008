# 无人机运行领域约定

服务面向低空运行、机队运维和合规管理人员。时间字段统一使用带时区的 ISO 8601
字符串，位置、授权和设备事件应保留来源时间与接收时间，不能用展示层文字替代
结构化状态。

健康接口只表示进程存活，不代表任何飞行或审批业务已经完成。需要落盘的数据应
使用运行时配置指定的位置（`STORE_FILE`），测试不得依赖主机上的隐藏状态。

## 适航管理模型

- **有效配置**：由部件拆装履历与固件激活记录按指定时刻推导，任一时刻对同一机体
  结果唯一；任务放行时将配置固化为快照，历史飞行引用快照，不随当前装配改变。
- **连续履历**：同一安装位置、同一部件的拆装事件不得交叠，不允许向履历中间回插；
  一个部件同一时刻只能装在一个机体上。
- **占用互斥**：任务占用（计划时段）与维修占用（停场工单开立至关闭）互斥，
  占用冲突时禁止放行、禁止装配变更，全部变更在存储锁内原子完成。
- **放行评估**：寿命（已同步且未超限）、必检签名（在有效期内且签字人资质覆盖
  签署时刻）、固件批准、工单关闭、载荷兼容与限重、环境限制、占用冲突全部通过
  才放行；任一不满足即拦截并返回结构化阻断项。
- **紧急放行**：仅适航工程师批准，批准人不得为申请人或涉事签字人；只能覆盖
  文书/资质类阻断，并带失效时间与附加循环上限等明确条件，条件耗尽即自动失效。
- **迟到日志**：按快照补计寿命（已被人工同步覆盖的部件不重复计数），输出受影响
  任务清单（含新阻断/曾超限飞行/寿命依据变化）与复检范围。
- **岗位视图**：机务看寿命与签名依据，调度看可执行结论与阻断项，接口按角色
  投影，越权访问返回 403。
