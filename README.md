# 无人机适航管理服务

面向无人机巡检公司的 Python 适航管理服务：基于机体、可序列化部件、固件、维修工单、
检查签名、任务载荷与环境限制，计算指定时刻的**有效配置**与**放行结论**，条件不满足时
拦截任务；并支持紧急放行、迟到飞行日志追溯与按岗位裁剪的两类视图。

需要 Python 3.11+，仅使用标准库。

## 运行

```bash
python src/index.py              # 启动服务，默认 0.0.0.0:8000
python -m unittest discover      # 全部测试（26 个）
docker compose up --build        # 容器方式
```

设置 `AIRWORTHINESS_DATA=/path/to/state.json` 可将登记与履历数据落盘（原子写入）；
不设置时数据仅存内存，测试不依赖主机隐藏状态。

## 领域规则

- **连续履历，时间点查询**：部件每次拆装生成 `[installedAt, removedAt)` 半开区间，
  装机时必须同步既往循环/小时读数（有寿命限制的部件缺读数直接拒绝装机）。
  有效配置是对任意时刻的纯函数查询——当前重新装配不改变历史时刻配置；
  飞行日志受理时额外固化一份配置快照，之后永不变更。
- **寿命**：部件寿命 = 装机同步基线 + 在翼区间内实际飞行；循环/小时分别计算并与
  到限值比较。机体寿命按全部飞行累计。
- **放行拦截**：评估生成结构化阻断项，覆盖装配空缺、窗口内拆装、寿命无同步依据、
  寿命到限、固件缺失/未批准、定检到期、**签字人资质在签字时刻过期或 scope 不符**、
  维修工单占用、任务窗口重叠、超载、风/温/降水越限。
- **紧急放行**：只能由独立角色（监管人员）批准，放行员与机务均不得自批；必须带
  失效时刻、可用飞行次数、指定任务、可覆盖阻断项清单与理由。硬性阻断
  （结构、寿命、固件、占用、环境）不可豁免；仅检查到期/签字资质类可被覆盖。
- **并发**：所有操作在同一存储锁内串行，同一机体同一时刻至多一个有效配置；
  维修与任务、任务与任务的窗口重叠都会被拦截。
- **迟到日志追溯**：日志区分飞行发生时间与受理时间（超过 1 小时宽限标 late）。
  补计后圈出：受影响部件的寿命前后值、新跨定检阈值的复检范围、新到限项、
  受理前做出的 GO/EMERGENCY_GO 评估（标记依据已被修订）、以及所有需重新评估的
  在计划任务。`GET /retro-impact` 汇总全部迟到日志影响。
- **岗位视图**：
  - 机务人员：`mechanic` 视图——有效配置、寿命读数与同步基线、签字资质依据；
  - 放行员：`dispatch` 视图——只有可执行结论（GO/NO_GO/EMERGENCY_GO）和阻断项，
    不含寿命数值与证书细节；
  - 监管人员：可访问全部视图并独占紧急放行批准；
  - 只读用户：仅任务计数级状态。

## 主要接口

业务接口需带 `X-Actor-Id` 请求头标明操作人。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/people`、`/people/{id}/certifications` | 人员与资质（资质仅监管可登记） |
| POST | `/aircraft`、`/components`、`/firmware` | 机体/部件/固件主数据 |
| POST | `/aircraft/{id}/installs`、`/removals` | 拆装履历（机务，装机带基线读数） |
| POST | `/aircraft/{id}/firmware-flashes` | 固件烧录 |
| POST | `/aircraft/{id}/inspections` | 检查记录（含签字人；资质在评估时判定） |
| POST | `/work-orders`、`/work-orders/{id}/close` | 维修工单占用 |
| POST | `/missions` | 任务（载荷、窗口、气象预报） |
| POST | `/missions/{id}/release-evaluations` | 放行评估，返回结论与阻断项 |
| POST | `/missions/{id}/emergency-releases` | 紧急放行（仅监管） |
| POST | `/flight-logs` | 飞行日志受理（可带 `receivedAt` 模拟迟到） |
| GET | `/aircraft/{id}/effective-config?at=` | 任意时刻有效配置（机务/监管） |
| GET | `/aircraft/{id}/views/mechanic?at=` | 机务视图 |
| GET | `/missions/{id}/views/dispatch` | 调度视图 |
| GET | `/retro-impact` | 迟到日志追溯汇总 |

健康接口 `/health` 只表示进程存活，不代表任何业务结论。
